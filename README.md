## ✨ Features

- **Fully Responsive Design** – Works on desktop, tablet, and mobile
- **Clean & Modern UI** – Card-based layout with smooth hover effects
- **Dynamic Content Loading** – JavaScript-powered blog post rendering
- **Performance Optimized** – Fast load times, minimal dependencies
- **Cross-browser Compatible** – Chrome, Firefox, Safari, Edge

## 🖥️ Tech Stack

| Technology | Purpose |
|------------|---------|
| **HTML5** | Structure & semantics |
| **CSS3** | Styling, Flexbox/Grid, animations |
| **JavaScript (ES6+)** | Interactivity, dynamic content |
